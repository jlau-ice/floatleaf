# 浮页使用说明

浮页把本地 TXT 小说显示在桌面上。书籍与进度保存在本机 SQLite，不需要账号或数据库服务。当前有 Apple Silicon macOS 与 Windows x64 试用构建；Windows 为交叉构建，尚待实机反馈。双平台实测范围见验收矩阵，面向试用者的简版说明见 TRIAL_GUIDE.md。

## 开始阅读

1. 打开 FloatLeaf，在“我的书架”点击“导入小说”。支持 20 MiB 以内的 TXT。
2. 核对预览。默认先按 UTF-8 读取，失败后尝试 GBK；出现乱码时手动切换编码。UTF-16 请先另存为 UTF-8。
3. 确认导入后，正文保存在书库中。原 TXT 可以移动，浮页不会修改或删除原文件。
4. 回到其他软件，按住 **Ctrl + Alt + 空格** 显示文字，松开隐藏。Mac 的 Alt 是 **Option / ⌥**。
5. 保持显示时，使用 **Ctrl + Alt + → / ←** 翻页；**Ctrl + Alt + P** 开始或暂停自动翻页。

默认快捷键可在“快捷键”页修改。每本书保存独立位置；再次点击书架里的书会从原位置继续。相同正文重复导入会复用已有书籍与进度。

## 显示方式

| 方式 | 行为 |
| --- | --- |
| 按住 | 按住显示快捷键时可见，任一组成键松开后隐藏 |
| 切换 | 按一次显示，再按一次隐藏 |
| 固定 | 点击后持续显示；可随时紧急隐藏 |

**Ctrl + Alt + Esc** 或设置/托盘中的“紧急隐藏”优先于三种模式。切换模式不会解除紧急隐藏；完全松开旧组合键，再重新按显示快捷键恢复。手动进入编辑布局是明确的预览操作，也会重新显示窗口。

每次启动、锁屏或休眠恢复后默认隐藏。锁屏、休眠通知已实现，实际系统恢复场景仍待双平台验证。

## 排版与布局

在“文字与布局”调整字体、字号、行高、字间距、颜色、文字不透明度、背景不透明度、阅读宽度、完整行数与翻页间隔。输入字体名称时需使用本机已有字体；不可用字体由系统回退。

位置锁定独立于显示方式。先“解除位置锁定”，再“编辑布局”：顶部手柄移动窗口，右下角手柄调整宽度和行数。点击“完成布局”后恢复鼠标穿透；按住/切换模式回到隐藏，固定模式继续显示。确认布局后可重新锁定。

改变排版保留当前文本锚点，因此显示百分比可能略变，已经阅读的位置不会跳回开头。高度按完整行计算；屏幕较小时行数和宽度会被约束到可用区域。只有空行的一页也会保留原文空行，继续翻页即可。

窗口找不到时，从托盘/菜单栏选择“找回阅读窗口位置”，再触发显示快捷键。它把位置恢复到主屏可见区域，不绕过紧急隐藏。

## 自动翻页

在“我的书架”的自动翻页按钮旁拖动“间隔”滑块，可设为 2～60 秒；修改后自动保存，并按新间隔重新计时。

按住模式下，可以先在隐藏状态点击“自动翻页”或“暂停自动翻页”，也可以用 Ctrl + Alt + P 开关。开启后显示“显示后继续”，按住显示快捷键才开始计时；松开后冻结剩余时间，再次显示时继续。编辑布局时同样暂停计时。手动翻页重置间隔，到最后一页自动停止。

隐藏期间不会自动或手动翻页；设置窗口的“上一页”和“下一页”按钮只在阅读窗口显示时可用。

## 快捷键与系统差异

点快捷键输入框后按所需组合，再保存。需包含 Ctrl、Alt 或 Super（Mac 的 ⌘ / Windows 的 Win），主键支持字母、空格、方向键、Esc、F1～F12。系统功能键可能需要同时按 Fn，取决于键盘设置。

五组键不能重复。系统报告注册冲突时会保留原快捷键；重新分配成功后窗口保持隐藏，重新触发即可显示。macOS 允许部分应用共享快捷键，系统未必报告所有占用；若系统或其他应用也响应，请换一组组合键。默认 Ctrl + Alt 组合在使用 AltGr 的键盘布局上也应实际检查。

全屏、Spaces、虚拟桌面、不同缩放与外接屏拔插尚未完成完整设备验收。不承诺覆盖独占全屏、UAC 安全桌面或系统锁屏。

## 退出与备份

关闭设置窗口只会隐藏设置。托盘/菜单栏可以再次打开设置、找回位置、紧急隐藏和退出；重复打开应用会打开已有设置窗口。

设置底部“本地数据位置”显示实际路径。正常退出后，备份该目录中的 `floatleaf.sqlite3`，其中包含小说正文、书架、每书进度、设置和窗口位置。恢复时先退出浮页，再复制备份文件替换数据库。不要在两个正在运行的实例之间复制正在写入的数据库。

“移除”需要再次点击确认，只移除书库副本及其进度，不删除原始 TXT。卸载程序默认保留本地书库，具体路径见安装说明。没有云同步或遥测上传。
