# FloatLeaf v0.1.2 · 按住模式自动翻页修复

- 按住模式隐藏时，现在可以通过设置按钮或 Ctrl + Alt + P 开启/暂停自动翻页。
- 开启后，隐藏期间保持进度和剩余时间；按住显示快捷键才继续计时，松开再次暂停。
- 自动翻页按钮旁新增间隔滑块，2～60 秒可调，自动保存；调整后按新间隔重新计时。
- 保留 v0.1.1 的 Windows 隐藏修复和日志入口，本次同时提供 Windows x64 与 macOS Apple Silicon 安装包。

## 更新和复测

先从托盘或菜单栏退出旧版，再安装新版，无需删除书库。在设置页底部“日志位置”确认版本为 **v0.1.2**。

1. 打开一本书，选择“按住”模式，保持阅读窗口隐藏。
2. 将自动翻页间隔调为 3 秒，点击“自动翻页”；等 3 秒以上，进度应保持不变。
3. 按住 Ctrl + Alt + 空格，文字显示后应按 3 秒间隔翻页；松开后暂停。
4. 在隐藏时点击“暂停自动翻页”，再次按住显示，内容应不再自动翻页。
5. 退出后重新打开，间隔设置应保留。若异常，从“日志位置 → 打开日志文件夹”取回 `.log` 文件和操作步骤。

## 验证范围

19 项 Rust、5 项浏览器测试及本机类型/格式/Clippy 通过；真实 macOS WebView/IPC/SQLite 中上述开关、计时和重启保存场景通过。两端普通 release 安装包已构建并核验，Windows 原生交互及用户设备复测仍需单独记录。

Windows 包未正式签名；macOS 包为 ad-hoc 签名，未公证。系统键鼠、锁屏/休眠、多屏等双平台验收尚未完成。详细证据见 [自动翻页修复记录](AUTO_READING_FIX.md)。
