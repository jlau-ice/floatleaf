# 浮页 FloatLeaf 试用说明

Windows / macOS 0.2.2 · 2026 年 10 月 17 日

浮页是一款离线 EPUB / TXT 悬浮阅读工具。导入小说后，文字可以像桌面歌词一样显示：按住快捷键阅读，松开隐藏。书籍、阅读进度和设置保存在本机，无需账号。

## 试用范围

Windows 本轮面向 Windows 11 x64；macOS 试用包面向 Apple Silicon。Windows v0.1.0 收到隐藏失效反馈，v0.1.1 修复原生隐藏并加入日志，尚待用户设备复测。macOS 已验证原生程序和阅读流程，真实键鼠、多屏、锁屏与休眠等场景仍需本轮试用反馈。

## 安装与打开

**Windows：**先从托盘退出旧版浮页。解压试用压缩包，双击其中的 `FloatLeaf_0.2.2_x64-setup.exe`，选择语言并完成安装，然后从开始菜单打开 FloatLeaf。无需删除书库。缺少 WebView2 时安装器会联网下载，请在首次安装时保持网络连接。日常阅读可离线使用。

v0.2.1 将 Windows 标题栏与设置页统一为暖白底、深绿文字，保留系统原生窗口按钮。请补测深色系统下的外观、最小化/最大化/恢复、标题栏拖动和贴靠；点击关闭仍只隐藏设置，可从托盘重新打开。

**反馈日志（v0.1.1 起）：**打开设置页底部“日志位置”，确认版本，点击“打开日志文件夹”。复现后发送其中的 `floatleaf.log` 和存在时的 `floatleaf.previous.log`，说明操作顺序和发生时间即可。日志不包含小说正文，无需发送数据库。Windows 备用路径为 `%APPDATA%\io.github.jlauice.floatleaf\logs`。

**macOS：**先从菜单栏退出旧版浮页，打开 `.dmg`，将 FloatLeaf 拖到“应用程序”，再打开应用。当前包仅配置 Apple Silicon，其他芯片请勿混用。

试用包没有正式发布签名，macOS 包也未公证。若系统提示来源未验证，请先确认文件来自本次试用，再按系统提供的选项确认；若被公司设备策略拦截，请反馈提示内容，不要关闭系统防护。

## 导入并开始阅读

1. 在“我的书架”点击“导入小说”，选择 EPUB 或 TXT。可先用压缩包内的合成示例文本。
2. 核对预览和章节数量。TXT 支持 UTF-8 和常见 GBK，最大 20 MiB；中文乱码时切换编码。EPUB 最大 100 MiB，提取文字与目录，正文上限 20 MiB。暂不支持 PDF、MOBI、AZW3、UTF-16 TXT、扫描图片书或加密正文。
3. 确认导入，选择“按住”显示模式，然后回到记事本、编辑器等其他软件。
4. 按住 **Ctrl + Alt + 空格** 显示文字，松开任一组成键隐藏。Mac 的 Alt 对应 **Option（⌥）**。

## 选择章节

进度条下方显示当前章节，可以点击“上一章 / 下一章”，或展开“章节目录”搜索并选择章节。隐藏时也能选章，窗口保持隐藏，按住显示快捷键才开始阅读；选中的位置立即保存。旧 TXT 书库升级时自动识别章节，无需重新导入。

EPUB 使用书内目录；无目录时按正文文件分节。TXT 识别“第 X 章”“Chapter 1”等独立标题，未找到章节时仍可逐页读。

## 默认快捷键

| 操作 | 快捷键 |
| --- | --- |
| 显示或隐藏 | Ctrl + Alt + 空格 |
| 上一页 | Ctrl + Alt + ← |
| 下一页 | Ctrl + Alt + → |
| 自动翻页暂停或恢复 | Ctrl + Alt + P |
| 紧急隐藏 | Ctrl + Alt + Esc |

按住模式下，保持显示组合键，再按左右箭头翻页。v0.1.2 起，可在隐藏时通过按钮或 Ctrl + Alt + P 开启/暂停自动翻页，显示后才继续计时。自动翻页按钮旁的“间隔”滑块可设为 2～60 秒，调整后自动保存并重新计时。隐藏时不会翻页。在“快捷键”页点击对应的「录制快捷键」按钮，看到「正在录制」后按下组合键，再点「保存快捷键」。录好后的「尚未保存」表示还没生效；单按 Esc 取消，Tab 或点击其他控件离开录制。若与系统或其他软件冲突，请换一组组合键。

## 日常使用

**显示方式：**“按住”是按住显示、松开隐藏；“切换”是按一次显示、再按一次隐藏；“固定”是持续显示。启动时先保持隐藏。位置锁定只控制布局编辑，不改变显示方式。

**紧急隐藏：**任何模式下均可使用。隐藏后，切换显示模式不会使文字重现；完全松开快捷键，再重新按显示快捷键即可恢复。主动进入布局编辑也会显示预览。

**调整文字与位置：**在“文字与布局”调整字体、字号、颜色、透明度、行高、字间距、宽度和行数。移动窗口时先解除位置锁定，再进入“编辑布局”，拖动顶部手柄；右下角手柄可调整尺寸。完成布局后恢复鼠标穿透，可重新锁定位置。

**自动阅读：**翻页间隔可设为 2～60 秒。隐藏或编辑布局时暂停计时，再显示后继续剩余时间；手动翻页重新计时，到结尾停止。每本书分别保存进度，改变排版仍保留阅读位置。

**退出与备份：**关闭设置窗口后应用仍在运行，可从托盘或菜单栏重新打开设置，或选择“退出浮页”。书籍已保存到本机，移动原文件 不影响阅读；移除书籍只删除书库副本。备份时先退出应用，再复制“本地数据位置”中的 `floatleaf.sqlite3`。

## 常见问题

**看不到文字：**先确认已经选中一本书、快捷键没有报冲突；若刚紧急隐藏，请全部松键再触发。仍找不到时，在托盘或菜单栏选择“找回阅读窗口位置”。

**无法拖动：**阅读状态下鼠标穿透是正常行为，请先解除位置锁定并进入布局编辑。

**设置关闭后如何找回：**点击托盘或菜单栏图标打开设置，或再次启动 FloatLeaf。应用会复用已有实例。

## 请重点试这几项

1. 分别导入 EPUB 和中文 TXT，核对目录、搜索和前后章；隐藏时选章后再显示，文字应从选中章节开始。退出重开后目录及位置恢复。
2. 分别先松空格、Ctrl、Alt，文字均隐藏；快速按放及长按没有残留。
3. 在记事本输入文字，显示、翻页、隐藏后仍能继续输入，无需重新点击输入框。
4. 选择固定显示，将阅读文字放在记事本上方；隔着浮字点击和拖选，应操作到底层窗口。
5. 紧急隐藏能覆盖三种显示方式，旧按键不能使内容自动重现；隐藏时自动翻页暂停。
6. 打开快捷键页，检查录制按钮、正在录制、取消、尚未保存与保存反馈；保存新组合键后实际触发，再按需要改回。
7. 如有条件，再测试外接屏、缩放变化、锁屏、休眠和全屏应用，记录实际表现。
