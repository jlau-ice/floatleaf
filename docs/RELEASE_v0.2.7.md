# FloatLeaf v0.2.7 · Windows 截图 / 录屏保护试用版

Windows 设置窗口底部新增「截图 / 录屏保护」。默认关闭，开启后通过 `WDA_EXCLUDEFROMCAPTURE` 在支持的捕获方式中排除悬浮阅读窗口，本地仍可阅读；设置自动保存，重启后保留。

只保护悬浮阅读窗口，书架、章节目录和导入预览所在的设置页仍可截图。需要 Windows 10 2004 或更高版本，不需要管理员权限。系统拒绝保护时，阅读窗口会隐藏并提示错误，可在设置中关闭选项后重试；日志包含实际保护标志与错误码。

当前 WebView2 不由浮页持有 DXGI 交换链，本版没有设置 `DXGI_SWAP_CHAIN_FLAG_DISPLAY_ONLY`。这不是绝对防泄漏保证，不承诺兼容所有截图/录屏工具，也不能防止拍照。macOS 暂不提供此开关；本版保留其菜单栏图标和阅读体验。

## 下载和升级

- Windows x64：`FloatLeaf_0.2.7_x64-setup.exe`。先从托盘退出旧版再安装，无需删除书库；也可用包含说明与校验值的试用 ZIP。
- macOS Apple Silicon：`FloatLeaf_0.2.7_aarch64.dmg`。先从菜单栏退出旧版，再拖入「应用程序」替换；最低 macOS 13.0。
- 两端未正式签名，macOS 为 ad-hoc 签名且未公证。附件 `SHA256SUMS.txt` 用于完整性校验。

## 请重点复测

1. 用自行编写的文字固定显示，保护关闭时截图应包含文字；开启后桌面仍显示文字，同一截图方式不应包含文字。
2. 保持显示直接关闭保护，应再次能截到文字；重新开启并退出重开，确认设置保存且保护仍有效。
3. 开启保护后试按住/切换/固定、编辑布局、翻页、松键和紧急隐藏，确认输入焦点与鼠标穿透正常。
4. 分别验证 Windows 截图工具、实际用的第三方截图工具、OBS 和会议共享模式；不同捕获来源可能不同。反馈请包含 OS 构建号、工具版本、具体模式与结果，异常时附日志，不必提供真实小说或聊天画面。

发布流程要求双平台类型/格式/Clippy、Rust 与浏览器检查，以及普通 Windows 安装包原生回归通过。Windows 捕获回归使用 GDI BitBlt/CAPTUREBLT 和合成文本，比较关闭 → 开启 → 关闭的实际像素，同时检查保护标志、焦点、穿透样式、松键与紧急隐藏。该结果不能代表所有捕获工具，也不能代替 Windows 11 实体设备、多屏、休眠、跨权限或物理键鼠验收。
