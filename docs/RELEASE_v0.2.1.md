# FloatLeaf v0.2.1 · Windows 标题栏优化

Windows 设置窗口的标题栏现在与页面使用一致的暖白底色和深绿文字。即使系统使用深色主题，标题栏和页面也保持协调。

保留 Windows 原生最小化、最大化、关闭按钮，以及标题栏拖动、双击最大化和贴靠行为。关闭设置仍隐藏到托盘，不退出阅读器。macOS 外观与阅读功能保持原状，本轮 macOS 下载沿用 v0.2.0。

## 安装与复测

Windows Server 2025 CI 已实际安装本安装器，43 项系统合成按键、原生显隐/焦点、窗口控制及标题栏像素检查全部通过；真实截图已核对。查看 [验证运行](https://github.com/jlau-ice/floatleaf/actions/runs/39040506097)。Windows 11 用户设备复测仍待反馈。

先从托盘退出旧版，再安装 `FloatLeaf_0.2.1_x64-setup.exe`，无需删除书库。在设置页底部“日志位置”确认版本 0.2.1。

1. 检查标题栏与页面是否同色，标题和三个窗口按钮是否清楚；可分别在系统浅色、深色主题下查看。
2. 测试最小化、最大化、恢复、拖动和双击标题栏、拖到屏幕边缘贴靠。
3. 关闭设置后，从托盘重新打开，书架和进度应保留。
4. 继续复测按住显示、不同松键顺序、紧急隐藏和自动翻页；异常时回传日志与操作步骤。

适用 Windows 11 x64；不同缩放、实际按钮悬停和鼠标贴靠仍需用户设备复测。包未正式签名；完整验证证据见 [Windows 标题栏记录](WINDOWS_TITLEBAR.md)。
