# 浮页 FloatLeaf 产品计划与技术方案

版本 0.1　日期 2026 年 10 月 17 日

浮页是一款 Windows 与 macOS 桌面悬浮阅读工具。用户导入本地小说后，可以按住快捷键显示文字，松开隐藏；也可以固定显示、手动翻页或自动翻页。界面参考桌面歌词，默认背景完全透明。

项目采用 Tauri 2、Vue 3、TypeScript 和 Rust，共用一个代码仓库，分别构建平台安装包。首版离线使用，通过安装包分发。开发首先验证两端的透明窗口、全局按键与焦点行为，再完善小说管理和排版。

## 1 产品目标与首版范围

核心体验是显示时不打断当前操作、松手后可靠隐藏、重新打开时继续阅读。悬浮文字不能抢走其他软件的输入焦点，阅读时默认允许鼠标点击穿透。

| 功能 | 首版要求 |
| --- | --- |
| 导入小说 | TXT 文件；UTF-8 与常见 GBK 编码；乱码时允许手动选择编码 |
| 按住显示 | 按下配置的快捷键显示，任一组成键松开即隐藏 |
| 切换显示 | 按一次显示，再按一次隐藏 |
| 固定显示 | 持续显示，不必一直按键 |
| 锁定位置 | 独立开关，固定坐标和尺寸，避免误移动 |
| 文字样式 | 字体、字号、颜色、字间距、行高、文字不透明度、阴影或描边 |
| 显示范围 | 单行、双行、多行；宽度和行数可调整，高度与完整行数联动 |
| 翻页 | 上一页、下一页快捷键；自动翻页、暂停与恢复 |
| 进度 | 每本书独立保存位置；退出或重启后恢复 |
| 系统入口 | Windows 托盘、macOS 菜单栏；设置、隐藏、退出 |
| 紧急隐藏 | 高于所有显示模式；立即隐藏并暂停自动翻页 |

后续版本考虑 EPUB、书签、全文搜索、样式预设和自动更新。首版开发优先级围绕 TXT 阅读闭环安排。

## 2 使用流程

打开书架并导入小说，设置文字位置与样式，回到正在使用的软件，按住快捷键阅读，松开隐藏。再次显示时保留原位置。设置窗口与悬浮阅读窗口分离，阅读时不必保持设置窗口打开。

## 3 交互规则与默认参数

显示模式包括按住显示、切换显示、固定显示。位置锁定与自动翻页是独立选项。编辑布局时暂时关闭鼠标穿透，显示边框与拖动手柄；完成编辑后恢复正常阅读状态。

| 参数 | 初始值 | 调节范围 |
| --- | --- | --- |
| 字号 | 18 px | 12 至 48 px |
| 显示行数 | 2 行 | 1 至 12 行 |
| 文本区域宽度 | 600 px | 200 至 1600 px，限制在当前屏幕内 |
| 行高 | 1.5 倍 | 1.0 至 2.2 倍 |
| 文字不透明度 | 70% | 10% 至 100% |
| 背景不透明度 | 0% | 0% 至 80% |
| 自动翻页间隔 | 8 秒 | 2 至 60 秒 |

文字与背景不透明度分开控制。窗口高度根据行数、行高和内边距计算；手动调整高度时换算为完整行数，避免半行文字。

### 显示与隐藏

- 阅读窗口显示时不抢焦点；设置窗口可以正常接受输入。
- 按住模式中，快捷键任一组成键释放都应隐藏；忽略重复的按下事件。
- 紧急隐藏立即隐藏并暂停自动翻页。仍按着旧快捷键时不能重新显示，必须完全释放后重新触发。
- 锁屏、休眠、模式变更或输入状态失效时清空按住状态；恢复后默认隐藏。
- 快捷键注册失败应反馈原因并保留可用入口，允许用户修改。

### 自动翻页与手动操作

仅在阅读窗口可见且自动阅读处于运行状态时计时。隐藏时暂停；再次显示后继续剩余时间。手动翻页后重置倒计时。到达结尾时停止，不自动跳回开头。

按住显示与翻页快捷键要组合验证；不得未经实测假定两组注册的组合键可以同时触发。阅读器隐藏时，除唤起和紧急隐藏外的阅读操作默认不改变进度。

## 4 技术选型与架构

Tauri 2 是首选：它使用系统 WebView，适合控制轻量桌面工具的分发体积，官方快捷键插件提供 Pressed 与 Released 事件。具体内存、CPU 和响应延迟必须通过原型测量。[1][2]

| 维度 | Tauri 2 | Electron |
| --- | --- | --- |
| 界面 | Vue 与 TypeScript | Vue 与 TypeScript |
| 桌面控制 | Rust | JavaScript 与必要的原生模块 |
| 运行环境 | 系统 WebView | 随包分发 Chromium 和 Node.js |
| 按键释放 | 官方插件提供释放事件，仍需验证语义 | 内置 globalShortcut 只有触发回调，需补释放检测 |
| 本项目选择 | 优先实施 | 已熟悉 Electron 的团队可作为备选 |

Electron 的全局快捷键回调与按键释放监听并不等价，不能直接用网页 keyup 完成无焦点场景下的松手隐藏。[3]

| 层次 | 选型 | 职责 |
| --- | --- | --- |
| 桌面框架 | Tauri 2 | 窗口、托盘、打包、系统接口 |
| 界面 | Vue 3、TypeScript、Vite | 书架、设置、悬浮文字 |
| 界面状态 | Vue composables | 表单和界面状态，不独立决定原生窗口可见性 |
| 核心控制 | Rust | 快捷键、显示状态、计时与文件处理 |
| 存储 | 嵌入式 SQLite（rusqlite bundled） | 小说正文、书架、阅读位置和设置 |
| 排版 | WebView 实际布局测量 | 按宽度和行数切页，缓存相邻页面 |

全局快捷键与托盘操作进入 Rust 阅读控制器，由它更新窗口和阅读会话。Vue 设置窗口通过命令读取和修改状态，悬浮窗口接收状态与当前文本。核心控制器保留唯一权威状态，避免两个窗口各自决定显示隐藏。

启动时预创建隐藏的悬浮窗口并准备文本。快捷键触发后直接控制原生窗口可见性，不在每次按键时重新创建窗口或解析整本小说。Windows 与 macOS 差异封装在平台适配层，共用阅读与业务逻辑。

## 5 关键实现与平台边界

### 按键与焦点

先使用 Tauri 官方 global-shortcut 插件。Windows 当前底层实现围绕主键检测释放，不能直接把 Released 理解为组合键任一成员释放。技术验证必须覆盖先松修饰键、先松主键、快速连续触发和长按重复，必要时补平台状态检查。[2][4]

窗口使用透明、无装饰、置顶及不获取焦点的配置。鼠标穿透属于独立系统窗口行为，不能仅使用 CSS pointer-events 代替。若需要更底层的输入监听，先评估实际 API 与 macOS 权限要求，再增加最小权限，不预先申请无关权限。[5]

### 分页与进度

分页以 WebView 实际排版为依据，按宽度和完整行数寻找文本边界。处理中文、英文长词、空行、标点及 Unicode 字符；等待字体就绪后再测量。只缓存当前与相邻页，避免将整本小说同时放入 DOM。

进度使用书籍内容标识、章节和文本位置，不能只保存页码。统一定义文本位置的计量单位，避免 JavaScript UTF-16 索引与 Rust UTF-8 字节偏移混用。变更字体或尺寸后重新分页，但保持当前阅读锚点。

导入小说时将正文、书架和进度存入应用数据目录的 `floatleaf.sqlite3`，设置也保存在数据库内；由 SQLite 事务维护一致性。进度节流保存，并在正常退出时刷新。导入和编码转换放到后台任务，避免阻塞窗口事件处理。

### macOS 透明窗口与分发

Tauri 的 macOS 完全透明窗口需要启用 macOSPrivateApi。官方明确说明使用该私有 API 的应用不能通过 Mac App Store 审核。因此首版采用独立安装包，正式分发安排签名与公证。如果商店上架成为硬性要求，应重新评估此方案。[6][7]

### 置顶与多桌面

首版保证普通桌面应用场景，macOS 全屏空间、Windows 虚拟桌面和独占全屏应用单独验证。Tauri 的所有工作区可见接口目前不支持 Windows，不能承诺完全一致的行为。UAC 安全桌面和系统锁屏不属于覆盖目标。[5]

多屏坐标使用逻辑尺寸与缩放信息保存；拔掉屏幕后将窗口恢复到可见区域。隐藏时暂停计时，长期运行避免高频轮询及不必要的持续渲染。

## 6 里程碑与验收

以下按一名熟悉 TypeScript、具备基本 Rust 能力的开发者且有两端测试设备估算，总体约 3 至 4 周。签名账号准备、外部等待和试用反馈另留时间。

| 阶段 | 投入 | 交付与进入下一阶段的条件 |
| --- | --- | --- |
| P0 技术验证 | 2 至 3 人日 | 两端演示透明置顶、按住显示、释放隐藏、不抢焦点、鼠标穿透 |
| P1 核心阅读 | 4 至 6 人日 | TXT 导入、分页、进度、手动与自动翻页、样式调整形成闭环 |
| P2 体验完善 | 3 至 5 人日 | 固定与编辑模式、快捷键设置、多屏恢复、异常处理完成 |
| P3 测试发布 | 2 至 3 人日 | 双平台验收记录、安装包、签名配置和使用说明齐全 |

P0 必须在 Windows 和 macOS 上分别记录结果。单端编译通过不能代表跨平台体验验收通过。若按键释放或窗口焦点不达标，先完成适配验证再扩展书架功能。

### 验收清单

- 其他软件输入期间显示、翻页、隐藏，输入焦点保持不变。
- 连续快速按放及任意释放顺序无残留、无延迟重新显示。
- 隐藏时停止自动翻页；恢复后位置和剩余时间正确。
- 调整字号、宽度、行数后没有漏字、跳字、截半行。
- 正常退出和重启后恢复每本书进度及样式。
- 多屏、缩放变化和外接屏断开后能找回窗口。
- 锁屏及休眠恢复后保持隐藏；旧按键状态不复活。
- 快捷键冲突时提示可理解，托盘仍可进入设置。
- 在约定测试机器上，以显示与隐藏 P95 延迟不超过 100 ms 为初步目标。
- 测量空闲、长按和自动翻页时的 CPU 与内存，检查持续增长和高频忙等。

性能数值是待验证的目标，不代表现阶段已实现。浏览器测试可以验证界面与分页，系统级快捷键、穿透、焦点和置顶必须用桌面程序验证。

## 7 开发环境与交付

项目目录为 ~/jlau-ice/floatleaf，采用 pnpm 管理前端依赖，rustup 管理 Rust。Node 版本写入 .nvmrc，pnpm 版本写入 package.json，Rust 版本写入 rust-toolchain.toml。pnpm-lock.yaml 与 Cargo.lock 纳入 Git。

仓库保留 README、AGENTS.md、产品计划、架构说明、任务清单、环境指南和 HANDOFF 交接记录。任务使用明确编号、依赖与验收条件，完成项须附验证证据。初始化只交付基础骨架，核心阅读能力由后续任务实现。

首轮验证平台为 Windows 11 x64 与本机 macOS Apple Silicon；Intel Mac 和其他 Windows 版本按测试设备与发布需求扩大覆盖。Windows 和 macOS 分别使用对应系统构建，macOS 构建成功不替代 Windows 验证。

Windows 提供安装程序，注意 WebView2 运行时；macOS 提供应用与 DMG。初期为本地开发构建，正式分发另配置签名、公证和发布流程。无账号和业务服务器时，持续成本主要来自安装包托管及签名相关费用。[7][8]
