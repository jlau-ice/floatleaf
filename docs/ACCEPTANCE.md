## 性能目标

预热后分别测量至少 100 次显示和隐藏，记录端到端 P50/P95/最大值；初步目标 P95 不超过 100 ms，不能仅以回调耗时替代可见结果。记录空闲 5 分钟、长按 60 秒和自动翻页 10 分钟的 CPU/内存趋势。当前没有性能实测结论。

## P2 阶段证据

同机原生测试：独立进程占用快捷键后的冲突反馈/保留原配置、重新绑定、完整行数尺寸调整、锚点保留、位置落盘和找回可见区域均通过；100 次显隐回归通过。17 项 Rust 测试通过。A13 尚缺实际多屏拔插，A14 的独占冲突程序路径通过，物理触发与系统共享快捷键限制见 `P2_LAYOUT_VERIFICATION.md`。Windows 仍无编译/实机证据。

## 2026-10-17 阶段证据

macOS 27.0.1 arm64：真实桌面程序启动，100 次原生显示/隐藏循环、紧急隐藏优先级、编辑/阅读态鼠标属性切换通过；窗口为非 opaque、level=5、非 key window。原生 WebView 截图目视检查通过。输入焦点连续性、实际鼠标点击和系统按键测试仍未完成，因此 A01～A08 仍标记待测。Windows 无编译或实机证据。

环境检查、类型、rustfmt、Clippy、5 项状态机测试与 debug 桌面构建通过。性能目标无实测通过结论。

## P1 阶段证据

macOS 同机真实 WebView/IPC/SQLite：UTF-8 与 GBK 导入、空文件拒绝、重复导入保留进度、切书、手动翻页、重排保持锚点、隐藏期间计时冻结、恢复续计时、手动重置与末尾停止均通过；移走源文件后重启恢复书架、设置与锚点通过（A11 本机通过）。A09/A10 的程序路径通过，物理键盘入口和不同字体人工观察仍待验收。14 项 Rust、3 项 DOM 测试与类型/格式/Clippy/debug 构建通过。详情及复现见 `P1_READ_VERIFICATION.md`。截图保存在忽略目录 `.local/p1-final/`，仅含合成验收文本。
