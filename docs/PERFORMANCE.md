# macOS 性能实测

日期：2026-10-17。Apple M5，10 个逻辑 CPU，16 GiB 内存；macOS 27.0.1 (26A434)，arm64；内置屏 3420×2224，缩放 2。Node 22.22.3、Rust 1.99.1。Windows 尚无结果。

## 方法与范围

采用 P3 阶段的优化 `diagnostics` 构建，通过真实 Tauri/WKWebView/SQLite 阅读 2,450,000 个 UTF-16 单元的合成文本。布局 600×2 行，18px 字号，1.5 行高，2 秒翻页。设置窗口隐藏，5 秒预热后每约 5 秒采样。

执行：`caffeinate -i node scripts/native-performance.mjs .local/performance .local/floatleaf-diagnostics`。二进制 SHA-256：`3a02aef332d19d474d0f8b69f33b142453afd7a736a8feb6c3600abadba2b77d`。这是加入单实例后的 P3 优化诊断版，采样期间随后修复的导入弹窗、移除非当前书与外观保存操作均未被执行；最终普通 DMG 不包含探针，也未直接测量它的性能。

通过 `ps` 累计 CPU 时间差除以实际经过时间计算平均 CPU，100% 表示占用一个 CPU 核心。统计主进程 53111 与本应用两个 WebContent 进程 53114、53116 的 RSS 总和；不含共享 GPU/网络服务，共享内存可能重复计入。包含文件诊断探针开销；期间主机有构建活动，结果不代表所有设备。

## 结果

| 场景 | 时长/样本数 | 平均 CPU | RSS 起点 → 终点 | RSS 最大值 |
| --- | --- | --- | --- | --- |
| 隐藏空闲 | 300.012 秒 / 61 | 0.607% | 233.23 → 54.92 MiB | 233.23 MiB |
| 固定显示静态页 | 60.013 秒 / 13 | 0.750% | 91.09 → 91.31 MiB | 91.36 MiB |
| 自动阅读 | 600.012 秒 / 121 | 3.168% | 92.97 → 109.81 MiB | 139.33 MiB |

采样时间为北京时间 10:04:21～10:20:22。逐个检查了全部样本：进程未替换，显隐状态符合各阶段，自动阅读阶段始终运行。隐藏时锚点保持 0；自动阅读锚点由 0 推进到 13612，没有停止或报错。10 分钟内 RSS 并非单调增长，但这不能证明长期运行不存在泄漏。

原始指标见 [CSV 样本](evidence/macos-performance-2026-10-17.csv)。完整探针 JSON 位于忽略目录 `.local/performance/performance.json`，不包含于交付包。

## 待测

- 固定显示 60 秒不是物理按住 60 秒；后者需要真实按键路径的独立采样。
- 显示和隐藏各 100 次的端到端可见帧 P50/P95/最大值尚未测量，不能声称 P95 ≤100ms。
- Windows、其他 Mac、干净设备与更长时间的趋势待验证。

复现前使用新的隔离目录，按 INSTALL.md 构建诊断版；结束后重新构建未带 `diagnostics` 的普通安装包。真实按键和帧采样步骤见 MANUAL_VALIDATION.md。
