# FloatLeaf v0.2.6 · macOS 菜单栏图标试用版

本次更新将 macOS 顶部菜单栏的彩色图标换为独立的单色「书页与叶子」图标，裁去素材多余留白，并启用系统模板着色。Dock 和应用图标、Windows 托盘图标沿用原样。

README 开头新增写给 LINUX DO 佬友们的话，欢迎社区试用与反馈。本版继续包含 v0.2.5 的 EPUB / TXT、章节导航、自动翻页、快捷键录制和紧急隐藏修复；阅读逻辑与本地数据库格式没有变化。

## 下载和升级

- macOS Apple Silicon（M 系列）：下载 `FloatLeaf_0.2.6_aarch64.dmg`，先从菜单栏退出旧版，再拖入「应用程序」替换。
- Windows x64：下载 `FloatLeaf_0.2.6_x64-setup.exe`；也可以下载试用 ZIP，其中附安装器、说明、MIT 协议与校验值。先从托盘退出旧版再安装。
- 原书库和进度保留，无需删除本地数据。macOS 最低 13.0，Intel Mac 暂无包；Windows 需要 WebView2。
- 附件 `SHA256SUMS.txt` 可核对安装包完整性。两端均未正式签名；macOS 使用 ad-hoc 签名且未公证。

## 验证范围与试用重点

版本发布流程要求 macOS / Windows 的环境、前端构建、类型、格式、Clippy、Rust 与浏览器测试全部通过；Windows 安装本轮普通 EXE 后执行原生回归，macOS 检查 app 签名、DMG 完整性及调试探针排除。附件上传后重新下载并校验，成功后才公开。

本机已完成菜单栏素材检查、调试桌面构建和 `.app` 设置窗口启动。菜单栏在不同深浅背景、选中状态下的观感及点击菜单仍待用户实机反馈，不以素材预览或编译代替验收。Windows 11 物理按键、拼多多跨权限、完整焦点/穿透、多屏、休眠和全屏场景仍待复测；Windows Server CI 合成输入不能代替这些测试。

macOS 后台按住显示需要输入监控权限。请为实际使用的 `FloatLeaf.app` 授权，退出再打开；开发子进程和其他路径的同名应用不能借用该结论。本版不申请额外输入权限。

欢迎到 https://github.com/jlau-ice/floatleaf/issues 反馈。菜单栏问题请注明系统版本、深浅背景、屏幕缩放及异常现象；快捷键问题可附日志，无需上传真实小说或用户数据库。
