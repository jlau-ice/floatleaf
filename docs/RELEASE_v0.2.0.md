# FloatLeaf v0.2.0 · EPUB 与章节目录

- 支持 EPUB 2 / EPUB 3 导入，读取书内目录及章节顺序；提取纯文字用于悬浮阅读。
- TXT 自动识别常见中文、英文章节标题；原有 TXT 书库升级后自动补目录，保留阅读位置和设置。
- 显示当前章节，可搜索目录、点击选章，以及上一章/下一章。
- 隐藏时可以选章，位置立即保存，阅读窗口仍保持隐藏；重新显示后从选中章节开始。自动翻页开关保留，倒计时重置。
- 包含此前 Windows 隐藏修复、日志入口和 2～60 秒自动翻页间隔。

## 安装与试用

先从托盘或菜单栏退出旧版，再安装新版。书库无需删除；可先退出并备份设置页“本地数据位置”中的 `floatleaf.sqlite3`。安装后从“日志位置”确认版本为 **0.2.0**。

1. 分别导入 EPUB 和 TXT，检查预览里的章节数量与正文。
2. 在进度条下方展开“章节目录”，搜索标题并选择，检查当前章节和悬浮文字是否对应。
3. 按住模式隐藏时选择另一章，确认窗口保持隐藏；按住显示快捷键才显示该章。
4. 尝试上一章、下一章和调整字号；退出重开，确认章节位置保留。
5. 继续复测普通松键、紧急隐藏、不抢焦点和自动翻页；异常时发送日志与操作步骤，不需要发送数据库。

Windows 试用 ZIP 附带原创合成 EPUB 2/3、UTF-8/GBK TXT 示例及完整说明。

## 格式与验证范围

TXT 支持 UTF-8 / GBK，文件上限 20 MiB；EPUB 文件上限 100 MiB，单个资源与提取正文上限 20 MiB。EPUB 图片与原书样式不保留；无目录时按正文文件生成分节。TXT 依据独立标题识别，无法保证所有排版都能自动分章。暂不支持 PDF、MOBI、AZW3、加密正文或扫描图片书。

本机 27 项 Rust、7 项浏览器测试及类型/格式/Clippy 通过，真实 macOS 桌面导入、目录搜索、跳章、隐藏冻结及移走源文件后的重启恢复通过。Windows 用户设备的 EPUB 兼容性及系统交互仍待复测，具体结果以 [章节与 EPUB 验证记录](CHAPTERS_EPUB.md) 为准。

macOS 包为 ad-hoc 签名，未公证；Windows 安装包未正式签名。本次为公开试用版，不代表双平台完整系统验收完成。
