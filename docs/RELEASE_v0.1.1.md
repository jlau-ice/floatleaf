# FloatLeaf v0.1.1 · Windows 隐藏修复与日志复测版

本次提供 Windows x64 未签名安装包，供 v0.1.0 隐藏异常的复测。macOS 已有 v0.1.0 包仍可使用；本次源码中的日志入口也适用于 macOS。

## 改动

- 修复 Windows 松开快捷键后文字仍停留、紧急隐藏也无效的问题。原先用 Win32 显示窗口，却用 Tauri 隐藏；Tao 内部的可见状态未更新，隐藏调用被跳过。现在 Windows 阅读窗口显隐统一使用原生调用。
- 设置页底部新增“日志位置”，显示版本、完整路径及“打开日志文件夹”按钮。
- 日志记录启动版本、快捷键注册/触发、要求显隐状态、系统实际可见状态、焦点和窗口错误。不记录小说正文、书名或普通打字内容，不自动上传。
- 日志最多保留当前和上一份两个文件，每份约 1 MiB。普通安装包可直接产生日志，无需开发环境。

## 请这样复测

1. 从托盘退出旧版浮页，再运行 `FloatLeaf_0.1.1_x64-setup.exe` 安装。无需删除书库或卸载数据。
2. 打开设置页底部“日志位置”，确认显示 **v0.1.1**。
3. 选择“按住”模式，按 Ctrl + Alt + 空格显示，分别先松空格、Ctrl、Alt，检查文字是否立即隐藏。
4. 保持显示组合键，按 Esc 紧急隐藏；保持旧按键时不能重新出现。全部松开后，再次按显示组合键应恢复正常。
5. 如果仍有问题，马上点“打开日志文件夹”，将 `floatleaf.log` 和存在时的 `floatleaf.previous.log` 发回，并说明大致发生时间、操作顺序和 Windows 版本。无需发送小说或数据库。

Windows 默认日志位置：`%APPDATA%\io.github.jlauice.floatleaf\logs`。界面无法打开时，也可将此路径粘贴到资源管理器地址栏。

## 验证范围

本机类型检查、rustfmt、Clippy、18 项 Rust 测试和 5 项浏览器测试通过，Windows 普通 release/NSIS 交叉构建成功。新增 Windows 安装包回归脚本直接检查 HWND 的实际可见性和焦点，而不是仅检查控制器状态。

Windows 11 实机复测仍待反馈，不能据此声明问题已在该设备通过验收。完整证据见 [Windows 隐藏问题记录](WINDOWS_HIDE_FIX.md)。
